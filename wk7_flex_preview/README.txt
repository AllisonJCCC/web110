# Explore the Outdoors — Parallax Web Page

## Files
- `index.html` — semantic HTML structure
- `styles.css` — Flexbox layout, visual styling, parallax backgrounds, and responsive rules
- `images/` — place your image files here

## Required images
Add two landscape images that you have permission to use:
- `images/mountains.jpg`
- `images/ocean.jpg`

The mountain image is used for the opening hero and mountain section. The ocean image is used for the ocean section.

## Preview
Open `index.html` in a web browser. For best testing, check a desktop-sized window and a narrow/mobile-sized window.

## Notes
The classic parallax effect uses `background-attachment: fixed`, which some mobile browsers limit. The media query switches the backgrounds to normal scrolling on screens 600px wide or narrower.
